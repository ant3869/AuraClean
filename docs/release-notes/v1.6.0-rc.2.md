# AuraClean 1.6.0-rc.2 (release candidate) — DRAFT

> **DRAFT — not published.** This is a release candidate for testing. It is **not signed** (see below).

**What changed since `1.6.0-rc.1`:** AuraClean is now built on **.NET 10 LTS** (rc.1 was built on .NET 8, whose support ends 10 November 2026). There are no cleanup-logic, UI or security-policy changes. The original rc.1 artifacts are **not** replaced or relabelled; rc.2 upgrades them in place.

## Requirements

- 64-bit **Windows 10 or Windows 11** are the supported systems. The self-contained build bundles .NET 10; nothing else to install.
- **Administrator rights**: UAC prompt for the installer, and a UAC prompt each time AuraClean starts (it is built to run elevated).
- ~75 MB disk.

## Installation, upgrade, uninstall

Full instructions: [docs/INSTALL.md](../INSTALL.md).

- **Install**: run the MSI (or `msiexec /i <msi> /qn`). Installs to `%ProgramFiles%\AuraClean`, adds a Start Menu shortcut (optional desktop shortcut) and an Installed apps entry.
- **Upgrade**: run this MSI over `1.6.0-rc.1` (or install it fresh). Installed apps shows the numeric MSI version `1.6.2` (the label `1.6.0-rc.2` is in *Comments*). Older or identical versions are refused. Close AuraClean first; the installer will not close it for you.
- **Uninstall**: Settings → Apps → AuraClean. It also removes the scheduled tasks (`AuraClean_LaunchAtLogon`, `AuraClean_ScheduledCleanup`) and Explorer menu entries (`AuraCleanUninstall`) that AuraClean's Settings may have created; upgrades and repairs leave them alone. **Your settings, logs, cleanup history, leftover backups (needed for restore) and quarantine in `%LocalAppData%\AuraClean` are never removed** by install, upgrade or uninstall.
- **From an older `install.ps1` install**: the MSI leaves the old copy alone and tells you about it; remove it later, if you wish, with `scripts/Remove-LegacyInstall.ps1 -WhatIf` first. Your data needs no migration.

## Known limitations

- **Not signed.** The MSI and EXE carry no Authenticode signature, so Windows shows "Unknown publisher" and SmartScreen may warn. Signing is an owner decision (see [docs/SIGNING.md](../SIGNING.md)).
- Automated real-`msiexec` tests (install, repair, original rc.1 → rc.2 upgrade, downgrade refusal, uninstall, data and integration preservation) pass on disposable **Windows Server 2022 and 2025** runners (administrator, UAC off), and the published EXE starts on its own bundled runtime there. They have **not yet been verified on Windows 10 or Windows 11 client systems**, nor UAC prompts, SmartScreen, the installer wizard or the running-app "files in use" behaviour; see "Release gates" in [docs/RELEASE.md](../RELEASE.md).
- The installer's launch condition only requires 64-bit Windows (Windows Installer reports a capped OS version), so it also runs on some older 64-bit Windows versions; those are unsupported and untested.
- The installer's Restart Manager auto-close is disabled on purpose: if AuraClean is running during an upgrade, you get the standard "files in use" prompt, or a reboot is needed when installing silently.
- Some features need an elevated, non-sandboxed environment and are covered by automated tests with synthetic data rather than end-to-end runs on a clean VM (for example DISM component-store cleanup, Force Delete and a real uninstall flow).
