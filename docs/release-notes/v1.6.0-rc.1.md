## Requirements

- 64-bit **Windows 10 or Windows 11**. The self-contained build bundles .NET 8; nothing else to install.
- **Administrator rights**: UAC prompt for the installer, and a UAC prompt each time AuraClean starts (it is built to run elevated).
- ~75 MB disk.

## Installation, upgrade, uninstall

Full instructions: [docs/INSTALL.md](../INSTALL.md).

- **Install**: run the MSI (or `msiexec /i <msi> /qn`). Installs to `%ProgramFiles%\AuraClean`, adds a Start Menu shortcut (optional desktop shortcut) and an Installed apps entry.
- **Upgrade**: run the newer MSI over it. Close AuraClean first; the installer will not close it for you.
- **Uninstall**: Settings → Apps → AuraClean. **Your settings, logs, cleanup history, leftover backups (needed for restore) and quarantine in `%LocalAppData%\AuraClean` are never removed** by install, upgrade or uninstall; delete that folder yourself only if you want them gone.
- **From an older `install.ps1` install**: the MSI leaves the old copy alone and tells you about it; remove it later, if you wish, with `scripts/Remove-LegacyInstall.ps1 -WhatIf` first. Your data needs no migration.

## Signing status and what Windows will show

**This build is not Authenticode-signed.** Windows does not treat it as coming from a verified publisher:

- The installer's UAC prompt shows **Unknown publisher**.
- A downloaded file may trigger SmartScreen ("Windows protected your PC") → *More info → Run anyway*, only if the checksum matched.
- AuraClean's own launch UAC prompt also shows an unknown publisher.

Signing plan: [docs/SIGNING.md](../SIGNING.md).

## Known limitations

- **Not signed** (above). Expect warnings.
- The installer and upgrade/uninstall behaviour have been verified by automated inspection of the MSI (layout, data-safety rules, version consistency) but **not yet on a clean Windows machine**; see the manual release checks in [docs/RELEASE.md](../RELEASE.md). Treat install/upgrade/uninstall results as unconfirmed until those are signed off.
- Exercised so far on Windows 11 only; Windows 10 is supported by the installer's launch condition and .NET 8 but untested.
- Some features need an elevated, non-sandboxed environment and could not be exercised in isolation in CI (for example DISM component-store cleanup, Force Delete and a real uninstall flow); those paths are covered by automated tests with synthetic data, not by end-to-end runs on a clean VM.
- No automatic updater: install newer versions by running the newer MSI.
- Per-machine install only; there is no per-user installer.
- DPI scaling above 150% and multi-monitor mixed-DPI layouts have not been verified.
- The installer's Restart Manager auto-close is disabled on purpose: if AuraClean is running during an upgrade, you get the standard "files in use" prompt, or a reboot is needed when installing silently.
